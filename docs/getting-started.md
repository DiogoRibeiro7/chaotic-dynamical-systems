# Getting started

## Installation

Install the development version directly from GitHub:

\`\`\`r
install.packages("devtools")
devtools::install_github("DiogoRibeiro7/chaotic-dynamical-systems")
\`\`\`

Then load the package:

\`\`\`r
library(chaoticds)
\`\`\`

The package requires R 4.0 or newer and a working C++ toolchain when it is built from source.

## Simulate a chaotic orbit

The logistic map is

\[
x_{t+1} = r x_t(1-x_t).
\]

For \(r=3.8\), the system exhibits chaotic behaviour for typical initial states.

\`\`\`r
x <- simulate_logistic_map(
  n = 4000,
  r = 3.8,
  x0 = 0.2
)

plot(x, type = "l", xlab = "Iteration", ylab = "x")
\`\`\`

## Fit a block-maxima model

\`\`\`r
bm <- block_maxima(x, block_size = 50)
gev <- fit_gev(bm)

summary(gev)
\`\`\`

The GEV distribution can be written as

\[
G(z) =
\exp\left[
-\left(
1 + \xi\frac{z-\mu}{\sigma}
\right)^{-1/\xi}
\right],
\]

on the support where \(1+\xi(z-\mu)/\sigma>0\).

## Use peaks over threshold

\`\`\`r
u <- quantile(x, 0.95)
gpd <- fit_gpd(x, threshold = u)

summary(gpd)
\`\`\`

Because exceedances generated by a chaotic system can cluster, estimate the extremal index as part of the analysis:

\`\`\`r
theta <- extremal_index_runs(
  x,
  threshold = u,
  run_length = 2
)

theta
\`\`\`

## Profile-likelihood uncertainty

\`\`\`r
prof <- profile_likelihood(gev, parameter = "shape")
profile_ci(prof)
\`\`\`

For return levels:

\`\`\`r
profile_return_level(gev, return_period = 100)
\`\`\`
