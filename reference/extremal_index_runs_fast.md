# Fast extremal index estimation with automatic method selection

Fast extremal index estimation with automatic method selection

## Usage

``` r
extremal_index_runs_fast(x, threshold, run_length = 3, use_cpp = NULL)
```

## Arguments

- x:

  Numeric vector of data

- threshold:

  Threshold value

- run_length:

  Run length parameter

- use_cpp:

  Logical, whether to force C++ implementation (if available)

## Value

Extremal index estimate
