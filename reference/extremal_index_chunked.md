# Chunked processing for large datasets

Process very large datasets in chunks to manage memory.

## Usage

``` r
extremal_index_chunked(x, threshold, run_length, chunk_size = 1e+05)
```

## Arguments

- x:

  Numeric vector (large dataset)

- threshold:

  Threshold value

- run_length:

  Run length parameter

- chunk_size:

  Size of each chunk

## Value

Numeric extremal index estimate
