# Fast block maxima computation with automatic method selection

Fast block maxima computation with automatic method selection

## Usage

``` r
block_maxima_fast(x, block_size, use_cpp = NULL)
```

## Arguments

- x:

  Numeric vector of data

- block_size:

  Size of each block

- use_cpp:

  Logical, whether to force C++ implementation (if available)

## Value

Block maxima
