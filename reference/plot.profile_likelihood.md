# Plot a profile-likelihood curve

Plots the profile log-likelihood as a function of the profiled
parameter, with horizontal and vertical reference lines showing the LRT
cutoff and the CI endpoints.

## Usage

``` r
# S3 method for class 'profile_likelihood'
plot(x, ...)
```

## Arguments

- x:

  A \`profile_likelihood\` object.

- ...:

  Unused.

## Value

A ggplot object.
