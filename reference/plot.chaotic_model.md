# Plot chaoticds model fits

Delegates to the underlying model plot method when available.

## Usage

``` r
# S3 method for class 'chaotic_model'
plot(x, ...)
```

## Arguments

- x:

  Fitted model object returned by \[fit_gev()\] or \[fit_gpd()\].

- ...:

  Additional graphical arguments passed through.

## Value

The result of the delegated plotting method.
