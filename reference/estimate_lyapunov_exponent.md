# Estimate the Lyapunov exponent of a logistic map

Computes a simple estimate of the largest Lyapunov exponent for a
sequence generated by the logistic map.

## Usage

``` r
estimate_lyapunov_exponent(x, r = NULL)
```

## Arguments

- x:

  Numeric vector of observations from the logistic map.

- r:

  Optional numeric parameter of the map. If \`NULL\`, it is estimated
  from consecutive observations.

## Value

Numeric value giving the estimated Lyapunov exponent.

## Examples

``` r
data(logistic_ts)
estimate_lyapunov_exponent(logistic_ts[1:1000])
#> [1] 0.4147852
```
