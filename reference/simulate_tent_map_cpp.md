# Fast tent map simulation (C++ implementation)

Efficient C++ implementation of the tent map.

## Usage

``` r
simulate_tent_map_cpp(n, r, x0, noise_sd = 0)
```

## Arguments

- n:

  Number of iterations

- r:

  Parameter r

- x0:

  Initial value

- noise_sd:

  Additive Gaussian noise SD per iteration (default 0)

## Value

Numeric vector
