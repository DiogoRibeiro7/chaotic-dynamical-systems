# Smart logistic map simulation

Automatically selects C++ implementation for large n.

## Usage

``` r
simulate_logistic_map_smart(n, r, x0, force_r = FALSE)
```

## Arguments

- n:

  Number of iterations

- r:

  Parameter r

- x0:

  Initial value

- force_r:

  Logical, force R implementation

## Value

Numeric vector
