# Smart extremal index estimation

Automatically selects optimal implementation.

## Usage

``` r
extremal_index_runs_smart(x, threshold, run_length, force_r = FALSE)
```

## Arguments

- x:

  Numeric vector

- threshold:

  Threshold value

- run_length:

  Run length parameter

- force_r:

  Logical, force R implementation

## Value

Numeric extremal index estimate
