# Fast extremal index estimation using runs method (C++ implementation)

Efficient C++ implementation of the runs estimator for extremal index.

## Usage

``` r
extremal_index_runs_cpp(x, threshold, run_length)
```

## Arguments

- x:

  Numeric vector of data

- threshold:

  Threshold value

- run_length:

  Run length parameter

## Value

Numeric scalar of extremal index estimate
