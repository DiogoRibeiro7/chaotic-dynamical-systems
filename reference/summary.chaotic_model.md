# Summarize chaoticds model fits

Summarize chaoticds model fits

## Usage

``` r
# S3 method for class 'chaotic_model'
summary(object, ...)
```

## Arguments

- object:

  Fitted model object returned by \[fit_gev()\] or \[fit_gpd()\].

- ...:

  Unused.

## Value

A list with standardized summary fields.
