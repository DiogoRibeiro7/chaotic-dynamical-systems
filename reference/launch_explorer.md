# Launch Interactive Extreme Value Explorer

Launches a Shiny application for interactive exploration of extreme
value analysis in chaotic dynamical systems.

## Usage

``` r
launch_explorer(...)
```

## Arguments

- ...:

  Additional arguments passed to
  [`shiny::runApp()`](https://rdrr.io/pkg/shiny/man/runApp.html)

## Value

Launches the Shiny application

## Examples

``` r
if (FALSE) { # \dontrun{
launch_explorer()
} # }
```
